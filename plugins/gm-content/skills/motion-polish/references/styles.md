# Style presets

Ten looks that read well on phones, one preset per video (or per montage section). Never mix two looks in one shot. If none fits, say so and propose one.

| # | Preset | Looks like | Use for | Build notes |
|---|---|---|---|---|
| 1 | **Callout Kit** | Real product screen; hand-drawn circles/arrows draw themselves, marker labels | One feature on a real screenshot | SVG stroke-dashoffset draw-on, ~0.4 s each, one callout at a time |
| 2 | **Stack Split** | Top half: the action; bottom half: a satisfying loop | Before → after | Hard 50/50, both halves on one beat grid; loop must be seamless (frame 0 = last frame) |
| 3 | **Glass Icons** | Glossy translucent 3D icons on a soft gradient | "5 tools that…" lists, launches | CSS 3D or Three.js, one icon per beat, brand gradient |
| 4 | **Data City** | 3D bar skyline growing, lit windows | Real numbers only | Numbers must be real and sourced on screen, else don't use it |
| 5 | **Chat Story** | A messaging conversation plays out | Problem → solution stories | One bubble per beat, typing indicator, fictional names labelled as example; RTL bubbles for RTL languages |
| 6 | **Versus Split** | Diagonal split, two sides slam in, VS badge | Old way vs new way | Diagonal mask, one impact sound on VS, then one side wins |
| 7 | **Quiz Countdown** | Bright card, question, 4 answer pills, timer | Engagement posts | Answer revealed on the drop |
| 8 | **Karaoke Subs** | Clean subtitles in a dark glass box, active word highlighted | Talking-head or voice-over videos | Word timings from Whisper; highlight per word, never per letter |
| 9 | **Terminal** | Glowing terminal, typed commands and output | Developer tools, CLIs | Monospace, block cursor, one key sound per character |
| 10 | **Exploded View** | Object floats apart into tagged layers | "What's inside" a product or system | Three.js, light floor, layers separate on beats |
